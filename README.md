## What is published

Daily PDFs are attached to **Releases** — one file per day, 100 certificates per page, every page watermarked **China Unaffiliated Fans**.
Each release also carries an index workbook with the machine-readable data.

## Method

- Each certificate code is counted once; duplicates are excluded
- Entries without a readable code are excluded from the index
- Timestamps are the participation time printed on the certificate (Beijing time, UTC+8)
- Page layout: 10 × 10 grid, 100 certificates per page, read left to right, top to bottom

## How to verify

1. Open the daily PDF, e.g. `VoteCerts_2026-11-07.pdf`
2. Open the index workbook and pick a row — it lists the certificate code, its time, and its position (`PDF页码`, `页内位置(行-列)`)
3. Go to that page and grid position: the certificate there carries the same code
